# EVA-02 Classification Pipeline

DIMER inference wrapper for **`timm/eva02_base_patch14_448.mim_in22k_ft_in22k_in1k`** — ImageNet-1k image classification (1000 classes) at 448 px — pinned to an immutable Hugging Face revision and loaded only from a digest-verified local snapshot.

## Upstream alignment

- Model: `timm/eva02_base_patch14_448.mim_in22k_ft_in22k_in1k` (EVA-02 Base, patch 14, 87.1 M parameters, 107 GMACs)
- Revision: `81063ecfe9c381a16a19d06f396d6c7011aa426a`
- Upstream weight license: MIT
- Upstream task: image classification, 1000 ImageNet-1k classes, fixed 448×448 input (squash resize, CLIP mean/std)
- Repository adaptation: **none**; inference only

## Quick start

```python
from PIL import Image
from eva02_classification_pipeline import EVA02ClassificationPipeline, top_k_accuracy

pipe = EVA02ClassificationPipeline.from_pretrained()          # cuda:0 if available, else cpu (slow)
result = pipe.predict(Image.open("photo.jpg"), top_k=5)
print(result["predictions"][0]["predicted_label"], result["predictions"][0]["top_k"][0]["score"])
print(top_k_accuracy(result["predictions"], [target_index], k=1))
```

`score` is a softmax score over 1000 classes, not a calibrated probability; the reported label is the argmax. Every input is squash-resized to 448×448 (aspect ratio not preserved). A GPU is the intended device; see `MODEL_CARD.md` → Runtime for the measured numbers.

## Weights layout

```
weights/eva02-base-448/
  dimer-base-manifest.json   # modelId, revision, per-file bytes + sha256 (verified on every load)
  config.json                # timm pretrained_cfg: input size, mean/std, crop mode
  model.safetensors          # 348492484 bytes (float32), git-ignored
```

`from_pretrained()` calls `verify_snapshot()` first and refuses to load if any file is missing or its SHA-256 differs from the manifest. Without a snapshot, `allow_download=True` loads from the Hub through timm's `hf-hub:timm/eva02_base_patch14_448.mim_in22k_ft_in22k_in1k@81063ecfe9c381a16a19d06f396d6c7011aa426a` form; the default is to refuse. To stage the snapshot: `hf download timm/eva02_base_patch14_448.mim_in22k_ft_in22k_in1k --revision 81063ecfe9c381a16a19d06f396d6c7011aa426a --local-dir weights/eva02-base-448`, then write the manifest.

## Tutorial

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/kurtvalcorza/eva02-classification-pipeline/blob/main/tutorials/eva02_classification_colab.ipynb)

`tutorials/eva02_classification_colab.ipynb` is declared `E2E` under DIMER Notebook Specification 2.0 and is **standalone** (§3.6): generated by `tools/build_notebook.py`, it carries the pipeline module, model identity, manifest digests and runtime pins, so the exported notebook runs without this repository (parity enforced by `tests/test_notebook_parity.py`; see `tutorials/README.md`). Its default path generates a synthetic 320×240 gradient in code, surfaces `NUM_CLASSES`/`MAX_IMAGE_SIDE`/`MAX_BATCH`, stages the missing snapshot file with `stage_missing_files(..., allow_download=True)` and digest-verifies it with `verify_snapshot`, classifies through the public API (argmax decision, rank-ordered top-5 softmax scores), validates the input into an input manifest with `validate_inputs`, writes an `evaluation_report`, performs 100% in-kernel fine-tuning and fresh-boundary reload verification, and exports a provenance JSON plus a top-k CSV. The report is `not-measurable` on the default path because the synthetic sample has no ground truth; it carries `top_k_accuracy` at k=1 and k=5 only when a BYOD image comes with a ground-truth class index. CPU works but is slow; CUDA is used automatically. BYOD is optional and gated off by default.
